# Fatemeh Lashkaripour — personal website

Live at **https://fatemehlashkaripour.github.io**

Plain HTML + CSS, hosted free on GitHub Pages. Every change uploaded to this repository goes live in about a minute.

## Update your job market paper (easiest)

Save the newest `paper.pdf`, `abstract.pdf` and `abstract.txt` in the Job market folder, then double-click
**Update website paper.command** in that folder. It copies the paper and abstract PDFs to the site,
updates the abstract text on the Research page, and publishes. The site updates in about a minute.

## Upload a new version of your paper (no software needed)

1. Go to https://github.com/fatemehlashkaripour/fatemehlashkaripour.github.io and open the **papers** folder.
2. Click **Add file → Upload files**.
3. Drag in your PDF. It must be named exactly **`Lashkaripour_JMP.pdf`**
   (rename it on your Mac first). Uploading a file with the same name replaces the old version.
4. Click **Commit changes**. Wait about a minute, then refresh your website.

The same works for:
- **Your CV**: the **files** folder, named `Lashkaripour_CV.pdf`
- **Research statement**: the **files** folder, named `Lashkaripour_Research_Statement.pdf`
- **Cannabis paper slides**: the **papers** folder, named `Lashkaripour_Cannabis_Slides.pdf`
- **Teaching statement**: the **files** folder, named `Lashkaripour_Teaching_Statement.pdf`
- **Your photo**: the **images** folder, named `headshot.jpg` (square works best)

## Files

| File | What it is |
|---|---|
| `index.html` | Home: banner, photo, About me, job market paper, tiles, research interests |
| `research.html` | Job market paper, working papers, publications, research agenda |
| `teaching.html` | Teaching experience |
| `cv.html` | CV download, references, education, awards, skills |

| `images/banner.jpg` | The purple watercolor banner |
| `files/Lashkaripour_CV.pdf` | Your CV |
| `papers/` | Paper PDFs (`Lashkaripour_JMP.pdf`, `Lashkaripour_JMP_Abstract.pdf`, slides) |

## Editing text

Open any `.html` file on GitHub, click the pencil icon, edit the words between the tags, and click **Commit changes**.

## Custom domain (optional)

Buy a domain (Namecheap, Cloudflare, Squarespace Domains), then on GitHub go to
Settings → Pages → Custom domain and follow the DNS instructions.
